# Contributing to FontForge Studio

First off, thank you for considering contributing to FontForge Studio!

## Getting Started
1. Fork the repository
2. Create your feature branch (`git checkout -b feature/AmazingFeature`)
3. Commit your changes (`git commit -m 'Add some AmazingFeature'`)
4. Push to the branch (`git push origin feature/AmazingFeature`)
5. Open a Pull Request

## Code Style
- Use pure ES6+ vanilla JavaScript (no frameworks)
- Maintain modular CSS using the existing file structure
- Follow semantic HTML practices
- Ensure accessibility (ARIA labels, keyboard navigation)

## Pull Request Process
1. Update the README.md with details of changes to the interface or new features if applicable.
2. Update the CHANGELOG.md with your changes.
3. The PR will be reviewed by maintainers before merging.

## Issues
Feel free to submit issues and enhancement requests. Provide as much detail as possible in your issue template!
