# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-07-24
### Added
- 3D interactive widget with CSS 3D transforms
- Wind-up toy key-start scroll mechanism
- 12 unique CSS motion effects
- 8 widget UI themes
- 15+ Google Fonts with dynamic loading
- 3 export methods (embed, download, snippet)
- Three.js 3D text export
- Responsive design
- GitHub Pages deployment
